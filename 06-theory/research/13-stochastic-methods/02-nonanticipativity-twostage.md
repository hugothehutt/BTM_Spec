## Provable under stated assumptions

### A.1 — What non-anticipativity *is*

| # | Claim | Exact assumptions | Source |
|---|---|---|---|
| A.1.1 | Non-anticipativity == measurability: `x_t` is admissible iff `x_t(ω)` is `F_t`-measurable, where `F_t = σ(ξ_1..ξ_t)` and `F_1 ⊂ F_2 ⊂ … ⊂ F_T ⊂ F`. | Filtration generated by the data process; `ξ_1` deterministic so `F_1 = {∅,Ω}`. | Shapiro–Dentcheva–Ruszczyński (SDR), *Lectures on Stochastic Programming* 2e, §3.1.4, eq. (3.16): "Condition (3.16) holds iff `x_t(ω)` is measurable with respect to `F_t`." |
| A.1.2 | Equivalent projection forms: `x_t = E[x_t | ξ_[t]]` (3.15) == `x_t = E[x_t | F_t]` (3.16) == `x = Px`, with `P` the orthogonal projection of `X` onto the non-anticipativity subspace `L` under `⟨x,y⟩ = Σ_k Σ_t p_k (x_t^k)ᵀ y_t^k`. | Finite `K` scenarios (for the algebraic form); `P` self-adjoint and idempotent. | SDR §3.1.4 eqs. (3.15)–(3.17); two-stage case §2.4 eqs. (2.84)–(2.86). |
| A.1.3 | Rockafellar–Wets formulation: policies live in `E = {X : S → R^n}`; **implementable** policies form the subspace `N := {X : X_t constant on each bundle A ∈ A_t, t=1..T}` (eq. 1.3); **admissible** policies form `C := {X : X_t(s) ∈ C_s ∀s}` (eq. 1.4); the problem is `min F(X) = E[f_s(X(s))]  s.t.  X ∈ C ∩ N` (eq. 1.10). The aggregation operator `J : X ↦ X̂`, `X̂_t(s) = Σ_{s∈A} p_s X_t(s) / Σ_{s∈A} p_s`, **is** the conditional expectation operator `E[X_t | F_t]` and the orthogonal projection onto `N`; `K = I − J` projects onto `M = N⊥`. | `S` finite; weights `p_s > 0`. **Nesting of the partitions `A_t` is NOT required** — RW1991 explicitly: "None of what we say in this paper actually depends on such an assumption." Each `A_t` must still be a partition of `S`. | Rockafellar & Wets, *Scenarios and Policy Aggregation in Optimization under Uncertainty*, Math. OR 16(1):119–147, 1991, eqs. (1.2)–(1.10), (2.1)–(2.5). |

### A.2 — Structural (compact/implicit) vs split-variable (explicit/scenario) form

| # | Claim | Exact assumptions | Source / proof |
|---|---|---|---|
| A.2.1 | **Split form ≡ original.** The scenario-decomposed problem (3.12) plus NACs `x_t^k = x_t^l` for all `k,l` with `ξ_[t]^k = ξ_[t]^l` (3.14) is equivalent to the original multistage problem (3.6). Two-stage case: (2.80)+(2.82) ≡ (2.61). | Finite scenario set; the tree/filtration used to define "same history" is the *true* information structure; the objective is the separable expectation `Σ_k p_k f_k(x^k)`; per-scenario feasible sets. | SDR §3.1.4: "Problem (3.12) together with the nonanticipativity constraints (3.14) becomes equivalent to our original formulation (3.6)." §2.4: "Clearly, the above problem (2.83) is equivalent to problem (2.61)." |
| A.2.2 | **Structural form ≡ split form, exactly.** Deleting the scenario index on a variable block is variable *elimination* on the equality system `x^1 = x^2 = … = x^K`. The map `(x, y_1..y_K) ↦ (x,…,x, y_1..y_K)` is a bijection between the compact feasible set and `{split feasible set} ∩ L`, and preserves the objective term by term. Hence **same feasible set (up to that bijection), same optimal value, same optimal solution set.** | Requires only: (i) the un-indexed variable is shared by **every** scenario in the model — i.e. its node is the *root* of the sub-tree the model spans; (ii) each scenario's constraints reference that one symbol. **No convexity, no continuity, no integrality assumption is needed** — this is linear-algebraic elimination, not an optimisation argument. | Direct corollary of A.2.1 plus Gaussian elimination on the sparse chain systems SDR gives: `x_1=x_2, …, x_{K−1}=x_K` (2.87), and the node-chained multistage system (3.18)/(3.19) `M¹x¹ + … + M^K x^K = 0`. |
| A.2.3 | Scenario-dependent bounds on a first-stage variable (`rUp ≤ cap_s`) **do not** break the equivalence. Both forms then impose the constraint almost surely: `rUp ≤ min_s cap_s`. | — | Follows from A.2.2: `C = Π_s C_s` (RW1991 eq. 1.4) is a product set; `C ∩ N` intersects it with the diagonal. |
| A.2.4 | **But** A.2.3 silently converts a recourse constraint into a robust one. Without **relatively complete recourse** the induced first-stage feasible set can be empty or artificially small, and `EEV` / `EEV^t` can be `+∞`. | Relatively complete recourse: every first-stage-feasible `x` admits a feasible second stage for every `ξ`. | Birge & Louveaux, *Introduction to Stochastic Programming* 2e, ch. 3 (recourse definitions), ch. 4 (value measures). Maggioni–Allevi–Bertocchi note the multistage `EEV^t` "could be infeasible because too many variables are fixed from the deterministic problem". |

### A.3 — Where the structural form is NOT enough

| # | Failure mode | Precise statement | Source |
|---|---|---|---|
| A.3.1 | **≥3 stages: index-dropping must be per NODE, not per stage.** | Dropping the `s` index on a *stage-t* variable enforces `x_t^k = x_t^l` for **all** `k,l` — i.e. measurability w.r.t. `F_1 = {∅,Ω}`, the coarsest σ-algebra, not w.r.t. `F_t`. The correct compact form indexes by node `n ∈ T_t` (one copy per node). A stage-indexed compact form is not the multistage problem. | SDR §3.1.4 **Remark 3**: if only the stage-1 constraints (3.13) are enforced then "from the mathematical point of view the problem obtained becomes a two-stage stochastic linear program with K scenarios" (first stage `x_1`, second stage the block `(x_2,…,x_T)`). Same collapse written as constraint (9b) `x_m = x_n ∀ m,n ∈ T_t, t=1..T` in arXiv:2411.01370 §2. |
| A.3.2 | **Varying branching / incomplete scenario sets.** | The compact form presupposes that indistinguishability at each `t` is an **equivalence relation whose classes partition `S`**. RW1991 tolerates non-nested `A_t`, but still needs each `A_t` to be a partition. The sparse chain form (3.18) is valid **only after the scenarios are ordered so each bundle `S_t^ν` is a set of consecutive indices** — SDR states this as an assumption, and it fails for scenario-dependent index sets. With incomplete scenario sets the minimal NAC set is not a chain and must be *generated* as a spanning-forest problem on the indistinguishability graph. | SDR §3.1.4 ("Let us assume that all scenarios 1,…,K are ordered in such a way that each set `S_t^ν` is a set of consecutive numbers"); *A Graph Theoretic Approach to Non-Anticipativity Constraint Generation in Multistage Stochastic Programs with Incomplete Scenario Sets*, arXiv:1908.01792. |
| A.3.3 | **CVaR does not break the compact/split equivalence — but it breaks scenario separability, and the CVaR auxiliary variable must itself be non-anticipative.** | Rockafellar–Uryasev: `CVaR_α(Z) = min_η { η + (1/(1−α)) E[(Z−η)_+] }`. The `min` sits **outside** the expectation. If `η` is given a scenario index `η_s`, the model computes `Σ_s p_s min_{η_s}{…}` which is a **strict under-estimate** of `CVaR_α` (interchange of `min` and `E`). So `η` must be first-stage / node-measurable. The A.2.2 equivalence is untouched (it is a statement about the variable space, independent of the objective), but RW1991's separable objective `F(X) = Σ_s p_s f_s(X(s))` (eq. 1.9) no longer holds, so the *decomposition* premise of Progressive Hedging fails unless `η` is carried as a shared variable. | Rockafellar & Uryasev, *Optimization of Conditional Value-at-Risk*, J. Risk 2(3):21–41, 2000, Thms 1–2. PH with risk measures: *Solving Stochastic Programming Problems with Risk Measures by Progressive Hedging*, Set-Valued Var. Anal., 2018, doi:10.1007/s11228-017-0437-4. |
| A.3.4 | **Joint chance constraints break the product structure of the admissible set.** | RW1991 requires `C = {X : X_t(s) ∈ C_s ∀s}` — a **product set** (eq. 1.4). A joint chance constraint `P(soc[s,t] ∈ [socMin,socMax] ∀t) ≥ 1−ε` couples scenarios: feasibility of scenario `s` depends on which *other* scenarios are satisfied. Consequences: (i) the second stage no longer decomposes per scenario; (ii) per-scenario L-shaped/Benders cuts are invalid without the indicator binaries; (iii) the indicator/big-M MIP has a weak continuous relaxation. Dual decomposition still applies but the coupling becomes a knapsack over the indicators. | Ahmed, Luedtke, Song, Xie, *Nonanticipative duality, relaxations, and formulations for chance-constrained stochastic programs*, Math. Prog. 162:51–81, 2017, doi:10.1007/s10107-016-1029-z. |
| A.3.5 | **Integer first stage: the LP relaxations of the compact and split forms have the SAME value — neither is tighter.** | The LP relaxation of the split form is `{(x_s,y_s) : per-scenario constraints, x_1 = … = x_K}`, which is in bijection with the LP relaxation of the compact form with identical objective. Splitting is a *lifting by equalities*, which cannot change an LP bound. So the structural form loses **nothing** in root LP strength — and it is smaller and branches on one `x`. | Immediate from A.2.2 applied to the continuous relaxation. |
| A.3.6 | **What the structural form DOES forfeit: the Lagrangian/dual bound.** | Relaxing the *explicit* NACs with multipliers `λ_j` (`Σ_j λ_j = 0`) gives `z_LD = max_λ Σ_j D_j(λ_j)`, and (Carøe–Schultz Prop. 2) `z_LD = min { Σ_j p_j (cᵀx_j + q_jᵀy_j) : (x_j,y_j) ∈ conv(S_j), x_j = x̄ ∀j }`. Since `conv(S_j) ⊆ LP(S_j)` we get `z_LP ≤ z_LD ≤ z`, and `z_LD` is "typically, but not always, strictly less than `z`" (MILP duality gap). This bound **exists only in the split form** — the compact form has no NAC multipliers to relax. Same for PH, which is defined on `E` with the projection `J` and requires the split variables. | Carøe & Schultz, *Dual decomposition in stochastic integer programming*, OR Letters 24:37–45, 1999, doi:10.1016/S0167-6377(98)00050-9; restated as Prop. 1 in Lubin, Martin, Petra, Sandıkçı, *On parallelizing dual decomposition in stochastic integer programming*, OR Letters 41(3), 2013. |
| A.3.7 | **PH convergence holds only in the convex case.** | RW1991 **Theorem 5.1** (convex case, exact minimisation): the iterates `{X̂^ν}, {W^ν}` are bounded **iff** optimal solutions exist for (P) and (D); then `X̂^ν → X*`, `W^ν → W*`, with Fejér monotonicity `‖(X̂^{ν+1},W^{ν+1}) − (X*,W*)‖_r ≤ ‖(X̂^ν,W^ν) − (X*,W*)‖_r`, strict unless already optimal (5.3). **Theorem 5.2** (linear-quadratic): linear rate `θ_r ∈ [0,1)` from the start. **Theorem 5.4**: approximate minimisation under a summable-error criterion. The standing hypothesis of "the convex case" is `f_s` convex and `C_s` convex. | RW1991 §5, Thms 5.1, 5.2, 5.4. The non-convex case gets only "rudimentary analysis" in §6 — **no convergence guarantee for MILPs**; PH on MILPs is a heuristic. |

### A.4 — The real trade-off

| Form | Non-anticipativity | Size | Root LP bound | Scenario decomposition | Dual bound |
|---|---|---|---|---|---|
| Structural / compact / implicit | Exact, by construction (A.2.2) | Smallest | Same as split (A.3.5) | **Impossible** | **None** |
| Split / explicit / scenario | Exact, as constraints (A.2.1) | `K ×` first-stage blocks | Same as compact | PH (RW1991); dual decomposition (Carøe–Schultz) | `z_LD ∈ [z_LP, z]` |

Correctness is a tie. The split form is bought **only** for decomposition and bounding.

### B.1 — Two-stage as a restriction of multi-stage

| # | Claim | Exact assumptions | Source |
|---|---|---|---|
| B.1.1 | **The two-stage approximation is the multistage problem plus NACs, hence a restriction.** Adding `x_m = x_n ∀ m,n ∈ T_t, t = 1..T` (all nodes at each stage collapsed to one) yields the two-stage model. Therefore `z^TS ≥ z^MS` and `VMS := z^TS − z^MS ≥ 0`. `[max: z^TS ≤ z^MS]` | Identical scenario tree, identical constraint and cost data; the *only* change is the coarsening of measurability. Holds for MILPs and for risk-averse objectives. | Huang & Ahmed, *The Value of Multistage Stochastic Programming in Capacity Planning Under Uncertainty*, Operations Research 57(4):893–904, 2009, doi:10.1287/opre.1080.0623. Explicit restatement, arXiv:2411.01370 §2 constraint (9b): "the risk-averse two-stage model (9) is the multistage model (8) with additional constraints (9b). We thus conclude that VMS_R ≥ 0". |
| B.1.2 | Huang–Ahmed give an **analytical lower bound** on VMS computable from the two-stage solution alone (no need to solve the multistage model). Later work adds a computable **upper bound** from the LP relaxation of the multistage model. | Huang–Ahmed: capacity-planning structure with **one-time acquisition costs**, expectation objective, deterministic first-period demand, a decomposable substructure; asymptotic optimality of their approximation scheme needs an **expanding-market** assumption. They give **lower bounds only, with no tightness guarantee**. | Huang & Ahmed 2009; arXiv:2411.01370 (Thm 1: lower bound from the two-stage optimal solution; Thm 2: upper bound from the multistage LP relaxation; Example 1: tightness instance). |
| B.1.3 | Risk-averse VMS bounds require the risk measure to be an **Expected Conditional Risk Measure (nested)**, not a static end-of-horizon CVaR. | Nested CVaR with per-stage weights `λ_t`; time-consistent by construction. | arXiv:2411.01370 §2 eq. (5); Homem-de-Mello & Pagnoncelli (ECRM). |

### B.2 — Classical value-of-information chain

| # | Statement | Assumptions | Source |
|---|---|---|---|
| B.2.1 | `WS ≤ RP ≤ EEV` for the `H`-stage problem. `EVPI := RP − WS ≥ 0`, `VSS := EEV − RP ≥ 0`. `[max: reversed]` | Minimisation; `EEV` = optimal value of `RP` with all decisions up to stage `H` fixed at the average-scenario optimum. `EEV < ∞` requires the EV solution to stay feasible in every scenario, i.e. effectively **relatively complete recourse**; otherwise `VSS = +∞` and carries no information. | Madansky 1960; Birge & Louveaux ch. 4; restated as **Theorem 2.1** in Maggioni–Allevi–Bertocchi, *Measures of Information in Multi-Stage Stochastic Programming*. |
| B.2.2 | `EV ≤ WS` holds **only when the sole random elements are the right-hand sides** `h²(ξ¹), …, h^H(ξ^{H−1})`. | Jensen; `Q(x,·)` convex in the RHS. Fails with random technology/recourse matrices or random costs. | Maggioni–Allevi–Bertocchi, remark following Thm 2.1. |
| B.2.3 | Staged multistage version: `EEV^t` = value of `RP` with `x^(1..t)` fixed at the average-scenario solution; `VSS^t := EEV^t − RP`. Then `VSS^t ≤ EV − EEV^t`, `t = 1..H−1`. | **Multistage stochastic LINEAR programs with deterministic constraint matrices and deterministic objective coefficients**; randomness in the RHS only. Individual `EEV^t` problems may be infeasible. | Escudero, Garín, Merino, Pérez, *The value of the stochastic solution in multistage problems*, TOP 15:48–64, 2007, doi:10.1007/s11750-007-0005-4; restated as **Theorem 2.2** in Maggioni–Allevi–Bertocchi. |
| B.2.4 | Distinguish: `VSS` / `EVPI` measure the cost of ignoring the *distribution*; `VMS` measures the cost of ignoring the *filtration*. Different quantities; neither bounds the other. | — | B.1.1 vs B.2.1. |

### B.3 — Bounds from aggregation / relaxation

| # | Statement | Assumptions | Source |
|---|---|---|---|
| B.3.1 | **Jensen lower bound** (min): `E[Q(x,ξ)] ≥ Q(x, E[ξ])`; aggregating scenarios into their conditional means is a **relaxation** and gives a lower bound. | `Q(x,·)` convex in `ξ`. True for LP recourse with randomness in `h` and `T` (fixed `W`, fixed `q`); **false** for a random recourse matrix `W`; `Q` is *concave* in the cost vector `q`. `[max: reversed]` | Huang, Ziemba, Ben-Tal, *Bounds on the Expectation of a Convex Function of a Random Variable*, Operations Research 25(2):315–325, 1977; Birge & Wets 1986. |
| B.3.2 | **Edmundson–Madansky upper bound** (min): replace each marginal by a two-point distribution on the endpoints of its support. | `ξ` supported on a **bounded rectangle** with **independent components**; `Q(x,·)` convex. Cost is `2^d` function evaluations in the dimension `d` of `ξ`. | Edmundson 1957; Madansky 1959; Huang–Ziemba–Ben-Tal 1977; Birge & Wets 1986. |
| B.3.3 | **These bound the scenario-discretisation error, NOT the filtration-coarsening error.** They say nothing about the two-stage-vs-multistage gap. | — | Direct: they bound `E_ξ[·]` for a *fixed* information structure. |
| B.3.4 | **Nested Benders / nested decomposition** solves the multistage SLP exactly on a finite tree; its outer linearisation of each cost-to-go function gives a valid **lower** bound at every iteration (min), and any primal feasible policy gives an **upper** bound — the mechanism by which a terminal value function can be *certified* rather than assumed. | Multistage stochastic **linear** program; relatively complete recourse (or feasibility cuts); finite scenario tree. Convexity of each `Q_t` in the state is essential and is **destroyed by binaries**. | Birge, *Decomposition and Partitioning Methods for Multistage Stochastic Linear Programs*, Operations Research 33(5):989–1007, 1985, doi:10.1287/opre.33.5.989. |

### B.4 — Rolling-horizon two-stage: the exact statement

| # | Statement | Assumptions | Source |
|---|---|---|---|
| B.4.1 | A rolling two-stage re-solve is a **policy**, not a restriction of the multistage program. The inequality `z^TS ≥ z^MS` (B.1.1) applies to the *static* two-stage model's optimal value and **does not** bound the realised performance of the rolling policy. The only universal relation is `J(π_rolling) ≤ J(π*) = V^MS` `[max]`; no non-trivial *a-priori* lower bound exists. | — | Powell, *A unified framework for stochastic optimization*, EJOR 275(3):795–821, 2019, doi:10.1016/j.ejor.2018.07.014, §"Evaluating a lookahead policy": the lookahead model is a *policy* for the base model and must be evaluated by simulation in the base model. |
| B.4.2 | **Bellman optimality / exact-value-function result.** `X*_t(S_t) = argmin_x { C(S_t,x) + min_π E[ Σ_{t'>t} C(S_{t'}, X^π_{t'}(S_{t'})) | S_t ] }`, equivalently `V_t(S_t) = min_x { C(S_t,x) + E[V_{t+1}(S^M(S_t,x,W_{t+1})) | S_t] }`. A **one-step lookahead using the exact `V_{t+1}` is optimal**; all loss is attributable to error in `V_{t+1}`. | Finite-horizon MDP; measurable selection / finite or compact action set; `V_{t+1}` exact; and `S_t` must be a genuine (sufficient) state — it must carry everything the transition and cost depend on. | Bellman 1957; Puterman, *Markov Decision Processes*, 1994, Thm 4.3.3 (finite horizon) / Thm 6.2.10 (discounted); Bertsekas, *DP and Optimal Control* Vol. I, Prop. 1.3.1. Powell 2019 eqs. (35)–(36) state exactly this as "an optimal policy using the base model". |
| B.4.3 | **The commonly repeated version is over-strong. Correct statement:** a lookahead of horizon `H` with an *exact* terminal `V_{t+H}` is optimal **iff the lookahead model is otherwise exact** — in particular iff its **stage structure** matches the base model. Powell enumerates the approximations a lookahead model makes: *limiting the horizon*; **stage aggregation** — "A common approximation is a two-stage formulation … where we make a decision `x_t`, then observe all future events (until `t+H`), and then make all remaining decisions"; *outcome aggregation or sampling*; *discretization*; *dimensionality reduction*. An exact terminal `V` removes only the **horizon-truncation** error. Stage aggregation *inside* the window survives and contaminates the implemented `x_t`. | Sufficient conditions under which stage aggregation is harmless: `H = 1` (one decision epoch in the window, then terminal `V`); or the within-window recourse value is affine in the within-window information; or no within-window decision depends on within-window information. | Powell 2019 §5.2 (the five approximation strategies) and §2.2 on the two-stage lookahead: "we have modeled the problem as if we make a single decision at time `t`, then see a scenario `ω` … Once this information is revealed, we then choose `x_{t+1},…,x_{t+H}`. In reality, we choose `x_t`, then see the information `W_{t+1}`, then we would choose `x_{t+1}` …". |
| B.4.4 | Without a terminal value function, a truncated rolling lookahead is **myopic and the gap is unbounded**: construct a storage instance whose only profitable price event lies beyond `t+H`; the policy earns 0, the optimum earns an arbitrary amount. | Deterministic construction; no discounting inside the horizon. | Standard end-effect argument, used explicitly by Gioia, Fadda, Brandimarte, *Rolling horizon policies for multi-stage stochastic assemble-to-order problems*, IJPR 62(14):5108–5126, 2024 (arXiv:2210.00491) §4: "the myopic behaviour of TS" is removed "by introducing a piecewise linear approximation of the value of the terminal inventory". |
| B.4.5 | Concavity of a terminal value function in a storage/inventory state is **provable, not assumed**, when the residual problem is an LP in that state: `V(I)` is the optimal value of an LP parameterised by the RHS `I`, hence concave in `I` for a maximisation. Binaries destroy this. | Fixed recourse LP; the state enters only the RHS. | Gioia et al. §4 ("Concavity of the value function is a consequence of the fact that …"); same mechanism as B.3.4. |

## Applicability to the target system

### Does structural non-anticipativity hold, given CVaR + joint chance constraint + MILP?

| Question | Verdict | Reason |
|---|---|---|
| Does omitting the `s` index on `rUp`, `rDn`, DA position correctly enforce non-anticipativity **within a single gate's two-stage model**? | **YES, exactly.** | A.2.2 — variable elimination on `x^1 = … = x^K`. Independent of CVaR, of the chance constraint, and of the binaries. No approximation whatsoever. |
| Does the CVaR term break it? | **NO** — but it imposes an invariant. | A.3.3. The equivalence concerns the variable space, not the objective. **INVARIANT: the Rockafellar–Uryasev auxiliary variable `η` must be first-stage — no `s` index.** If `η` is scenario-indexed the model silently computes something strictly smaller than `CVaR_α` and the risk term is largely inert. This is the most likely silent bug in the spec. |
| Does the joint chance constraint break it? | **NO** for non-anticipativity; **YES** for everything downstream. | A.3.4. `C` is no longer a product set (RW1991 eq. 1.4 violated) ⇒ the second stage does not decompose by scenario ⇒ per-scenario L-shaped cuts are invalid, and the indicator/big-M formulation has a weak LP relaxation. |
| Do the binaries break it? | **NO.** | A.2.2 needs no integrality assumption. A.3.5: the compact form's root LP bound equals the split form's — nothing is lost. |
| **What IS lost by the structural form?** | The dual bound and all scenario decomposition. | A.3.6. `z_LD` (Carøe–Schultz) is unavailable. With binaries + CVaR + a joint chance constraint the extensive MILP will be the bottleneck, and there is then **no** certified bound other than the solver's own. **Recommendation: maintain a split-variable twin of each gate model, used only to compute `z_LD`.** |
| Anything else at risk? | **YES — endogenous uncertainty.** | The ledger holds `Pending` entries weighted by a **fill belief**. If that belief is *exogenous* (a fixed probability), everything above holds. If the fill belief depends on the DA position or on `rUp/rDn` (i.e. on a decision), then the scenario probabilities — and hence the filtration — are **decision-dependent**. Non-anticipativity is then not a fixed linear subspace and cannot be enforced structurally; it requires conditional/disjunctive NACs (Goel & Grossmann 2006). The chance constraint's `1−ε` mass also stops being a constant. **Check this first: it is the sharpest correctness risk in half (A).** |
| Time consistency | **VIOLATED as specified.** | A static end-of-horizon `CVaR_α(imbalance + activation cost)` applied afresh at each of S1..S4 and re-solved is **time-inconsistent**: the S2 solve can rationally prefer to undo the hedge S1 bought. Shapiro 2009 proves exactly this for end-of-horizon CVaR. Fix: nested conditional risk mappings / ECRM (CVaR composed per gate) — which is also the only form under which B.1.3's risk-averse VMS bounds apply. |

### Does S1→S4 sit inside the known bounds on two-stage-approximating-multistage loss?

**Partly — and the part that does is not the part that matters.**

| Layer | Verdict |
|---|---|
| **Each individual gate's model, viewed statically** | **INSIDE the bound.** At S1 the model makes `rUp`, `rDn` **and** the DA position scenario-independent. Since the DA position is genuinely decided later (at S2, after S1→S2 information arrives), this is precisely the extra NAC of B.1.1 / constraint (9b). The gate model is therefore a **restriction** of the true 5-stage problem: its optimal value is a **lower** bound on the true multistage value `[max]`, `VMS ≥ 0`, and the Huang–Ahmed structural result applies. **The model is conservative, never anticipative.** This is the one clean piece of good news. |
| **Are the Huang–Ahmed *numeric* bounds usable?** | **NO, not off the shelf.** Their lower bound derives from a capacity-planning substructure with one-time acquisition costs and an expanding-market assumption; ours is a storage/reserve problem with a concave terminal `V`, a CVaR term and a joint chance constraint. Only `VMS ≥ 0` transfers. The **upper** bound via the LP relaxation of the multistage model (arXiv:2411.01370 Thm 2) is the transferable idea: build the 5-stage node-indexed LP relaxation once, offline, to size the gap. **Concrete recommendation.** |
| **The executed rolling policy S1→S2→S3→S4** | **OUTSIDE all of the above bounds.** B.4.1. `z^TS ≥ z^MS` characterises the static model, not the policy. Re-solving can beat the static two-stage value (it uses information the static model froze) or lose to it (inconsistent objectives across gates, terminal-`V` error). No a-priori bound exists. **The only admissible evaluation is out-of-sample simulation of the whole S0→S4 loop in a base model** (Powell 2019). |
| **Does the terminal `V(SOC)` rescue optimality?** | **NO — this is the sharpest correction to the spec's premise.** B.4.3. An exact `V` removes the **horizon-truncation** error only. Each gate's window still contains **multiple** information-then-decision alternations (S2→S3→S4, plus the continuous intraday re-optimisation inside S4) collapsed into a single recourse stage. That is Powell's **stage aggregation**, and it survives an exact `V`. The claim "two-stage lookahead + exact terminal value function = optimal" holds **only when the window contains exactly one decision epoch before the terminal state.** With four sequential commitment points, it does not. |
| **`V` conditioned on `(peakState, qualState, calendar)` — Jensen trap** | `V` is **concave** and enters a **max**. If `V` is evaluated at a scenario-independent SOC (e.g. `V(E_s[soc])`) instead of scenario-wise (`Σ_s p_s V(soc[s,T])`), the model **OVERSTATES** terminal value, since `V(E[soc]) ≥ E[V(soc)]` by Jensen. **INVARIANT: `V` must be indexed by `s` in the second stage.** Same for `peakState` / `qualState` whenever they are affected by second-stage decisions. |
| **Concavity of `V` — assumed or proved?** | **Assumed, and provably false in general here.** B.3.4 / B.4.5: an LP value function parameterised by an RHS state is concave, so a *relaxed* (binary-free) residual problem yields a concave `V`. With binaries in the stage problems the true cost-to-go is **not** concave. The concave PWL `V` is therefore an approximation of unknown sign — and B.4.2 says all policy loss is attributable to it. **S0 must produce `V` with a bound, not just a fit**: nested Benders on the LP relaxation (Birge 1985) for a certified over-estimate `[max]`, plus policy simulation for an under-estimate. |

### Ranked list of what violates what

1. **Fill-belief-dependent scenario weights ⇒ decision-dependent filtration.** Invalidates structural non-anticipativity itself (A.3.2; Goel–Grossmann). Check first, cheapest to check, most damaging.
2. **Scenario-indexed CVaR auxiliary `η`.** Silently replaces `CVaR_α` with a strictly smaller quantity (A.3.3).
3. **Static end-of-horizon CVaR re-solved at each gate ⇒ time inconsistency** (Shapiro 2009), and it puts the model outside the risk-averse VMS bounds of B.1.3.
4. **Stage aggregation inside each gate's window is NOT removed by the terminal `V`** (B.4.3). The spec's claimed "S1→S4 recourse structure" is a 4-alternation problem carrying a 1-alternation model.
5. **Joint chance constraint destroys the product structure of the admissible set** (A.3.4) ⇒ no per-scenario decomposition, weak LP relaxation, and PH is doubly inapplicable (non-convex *and* non-product).
6. **Binaries ⇒ no PH convergence guarantee** (RW1991 Thm 5.1 is convex-only) and **no concavity guarantee for `V`**.
7. **The structural form forfeits `z_LD`** (A.3.6). Not a correctness bug; a bounding gap. Mitigate with a split-form twin used for bounding only.
8. **NOT a violation:** the index-omission itself. It is exactly correct within each gate (A.2.2), requires no assumptions, and costs nothing in LP bound strength (A.3.5).
